# Topitot App

## Product Vision

Topitot is an AAC (Augmentative and Alternative Communication) application for non-verbal and speech-delayed children.

The goal of every feature is:

- Help children communicate quickly
- Minimize cognitive load
- Encourage independence
- Create positive emotional experiences
- Support parents, teachers, and therapists

Always prioritize accessibility over aesthetics.

## UI Design Rules

All UI elements must:

- Use rounded corners
- Use large touch targets
- Have high contrast
- Be usable by children ages 2-12
- Minimize text
- Favor icons and images

Preferred border radius:

16px
20px
24px

Avoid sharp corners.

---

## Typography

Headings:
Poppins Bold

Body:
Inter Regular

Buttons:
Poppins SemiBold

Never use decorative fonts.

---

## AAC Button Guidelines

AAC buttons must:

- Be large and easy to tap
- Include image + text
- Support audio playback
- Have consistent sizing

Minimum touch size:

80x80

Preferred:

120x120

---

## Illustration Style

Use:

- Friendly cartoon illustrations
- Diverse children
- Bright positive emotions
- Soft shadows
- Rounded shapes

Avoid:

- Hospital imagery
- Puzzle pieces
- Distressing visuals

## Accessibility

Every screen must support:

- High contrast mode
- Large text scaling
- Audio feedback
- Visual feedback
- Color-blind friendly indicators

Never rely solely on color.

---

## Animation

Animations should be:

- Gentle
- Fast
- Positive

Duration:

150ms - 300ms

Avoid flashy animations.

---

## Success Moments

When a child completes an action:

- Celebrate subtly
- Show positive feedback
- Avoid overstimulation

Examples:

⭐ Great job!

🎉 Nice talking!

❤️ Well done!

---

## Coding Standards

Use Flutter Material 3.

Create reusable design tokens.

Never hardcode colors.

Store all colors in:

lib/theme/app_colors.dart

Store typography in:

lib/theme/app_typography.dart

Store spacing in:

lib/theme/app_spacing.dart
