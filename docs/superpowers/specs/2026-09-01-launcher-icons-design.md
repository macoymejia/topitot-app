# Launcher Icons Design

## Context

Speech Relay by Topitot currently uses the default Flutter launcher icons on Android and iOS. The repo already contains a high-resolution square source image at `assets/images/speech-relay-by-topitot-logo-1000x1000.png`, which is the best source for generating launcher icons for both platforms.

The request is to replace the current Flutter launcher icon with this app artwork across Android and iOS, while keeping the in-app assets unchanged.

## Goal

Replace the default Flutter launcher icons on Android and iOS with icons generated from `assets/images/speech-relay-by-topitot-logo-1000x1000.png`.

## Non-Goals

- No changes to the in-app splash overlay.
- No redesign of the logo itself.
- No manual editing of platform icon sizes unless the generator requires it.
- No change to app behavior or AAC screens.

## Recommended Approach

Use `flutter_launcher_icons` to generate all required launcher icon sizes from a single 1000x1000 source image. This is the smallest maintainable option because it keeps the icon source centralized and updates both Android and iOS consistently.

Manual native icon replacement is possible, but it would require maintaining many files by hand and would be easier to break. Keeping the icons generated from one config is better for repeatability.

## File Structure

```text
assets/images/speech-relay-by-topitot-logo-1000x1000.png
pubspec.yaml
android/app/src/main/res/mipmap-*/ic_launcher.png
android/app/src/main/res/mipmap-anydpi-v26/* (if generated by tooling)
ios/Runner/Assets.xcassets/AppIcon.appiconset/*
```

## Components

### Source Image

The 1000x1000 PNG is the single source for both platforms. It should remain the canonical icon source for future regenerations.

### Launcher Icon Generator

`flutter_launcher_icons` will read the config from `pubspec.yaml` and generate the Android and iOS launcher icon sets from the source image.

### Platform Icons

Android will continue to reference `@mipmap/ic_launcher`. iOS will continue to reference the `AppIcon.appiconset` bundle. The generated files will replace the current Flutter defaults.

## Data Flow

1. The source PNG is already present in `assets/images/`.
2. `pubspec.yaml` declares the icon-generation config.
3. The generator creates platform-specific icon files.
4. Android and iOS launchers use the new icons automatically.

## Error Handling

- If the source image path is wrong, icon generation should fail during the generation step, not at runtime.
- If the launcher cache on Android shows the old icon, reinstalling the app should reveal the updated icon.
- If the generated iOS asset catalog is incomplete, the build should fail during Xcode/Flutter packaging rather than shipping a broken icon set.

## Testing

- Run the launcher icon generator after updating config.
- Run `flutter analyze` and `flutter test` to ensure no app code regressed.
- Build the app for Android and verify the installed launcher icon on a real device after uninstall/reinstall.
- Optionally verify the iOS icon set builds if an iOS build environment is available.

## Acceptance Criteria

- Android launcher icon no longer shows the Flutter logo.
- iOS launcher icon no longer shows the Flutter logo.
- Both platforms use icons derived from `assets/images/speech-relay-by-topitot-logo-1000x1000.png`.
- The app code and AAC behavior remain unchanged.
